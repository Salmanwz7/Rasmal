# Screenshots

Drop app screenshots here so they render in the main [`README.md`](../README.md).

## How to capture them

The easiest way (no local emulator needed):

1. Upload `app/build/outputs/apk/debug/app-debug.apk` to **[appetize.io](https://appetize.io)**.
2. Walk through the app and use appetize's **screenshot / camera button** on each screen.
3. Save each image into **this folder** using the exact filenames below (PNG).

## Filenames the README expects

| Filename | Screen |
|---|---|
| `01-signin.png` | Sign In |
| `02-signup.png` | Sign Up |
| `03-onboarding-portfolio.png` | Onboarding · Portfolio (stocks you own) |
| `04-add-stock-search.png` | Add a stock · search list |
| `05-add-stock-details.png` | Add a stock · shares + avg price |
| `06-onboarding-risk.png` | Onboarding · Risk appetite |
| `07-dashboard.png` | Dashboard |
| `08-ai-recommendation.png` | AI Recommendation |
| `09-ai-chat.png` | AI Chat |

> Tip: keep them portrait and a consistent width (e.g. ~1080px or a phone frame) so the README tables look tidy. Only `01`, `03`, `04`, `05`, `06`, `07`, `08`, `09` are shown in the README table; `02` is optional.
